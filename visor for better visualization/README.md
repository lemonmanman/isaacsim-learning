# Visor for better visualization
Robots in RVIZ don't look that good, so we usually use visor for better visualization (e.g: screenshots in README files) .

## Steps
Make sure you clone the repository first.
1. Launch your robot
2. Use the command below to run the code:
    ```bash
    python3 launch.py 
    ```
3. Open the website below:
    ```bash
   http://localhost:8080/ 
    ```
4. For better definition of the picture, you can change the **device pixel ratio** in Dev settings.
